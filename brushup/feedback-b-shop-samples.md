## §1. ぶたいのショップ連動

### 1-1. ★Chat が調べた対応関係（そのまま信じず、着手前に確認して報告）

エディタのぶたいは5種。**ショップで売っているのは2種だけ**だった。

| エディタの id | 画像 | ショップ商品 | 価格 |
|---|---|---|---|
| `sougen` | `bg_battle_easy.webp` | **無し**（バトルの既定背景） | — |
| `jungle` | `bg_battle_jungle.webp` | **`bg_jungle`**（`COSMETICS`・`data/battle.js`） | 100 |
| `canyon` | `bg_battle_canyon.webp` | **`bg_canyon`**（だいちの ぶたい） | 100 |
| `arena` | `battle-arena.webp` | **無し** | — |
| `studio` | `studio-interior.webp` | **無し** | — |

所持の判定は **`save.cosmetics.owned` に商品 id が入っているか**（`Shop.jsx` / `DressupShelf.jsx` と同じ作法）。

**この表が現物と合っているかを確認して報告すること。** 違っていたら手を止める。

### 1-2. 仕様（Chat が決めた）

- **`jungle` と `canyon` は、対応する商品を購入済みのときだけ選べる**（`bg_jungle` / `bg_canyon` が `owned` にあるか）
- **`sougen` / `arena` / `studio` は常に選べる**。売り物が存在しないため、隠すと選択肢がゼロになりうる。`sougen` は最初のぶたい
- **未購入のものは一覧に出さない**（神田さんの指示「購入できたもののみ表示」に従う）
- **studio と gamelab の両方に適用**（`BGS` は共有）

### 1-3. ⚠️ 既存作品の救済（★これを外すと事故になる）

**いまは5種すべてが誰でも選べる。** すでに `jungle` や `canyon` で保存された作品が存在しうる。

- **保存済み作品の見た目は変えない。** 未所持の背景で作られた作品も、**そのままその背景で表示・再生される**
- **その作品を開いたとき、選択欄にはその背景も表示する**（いま選ばれているものが一覧に無いと、何が選ばれているのか分からなくなる）
  ＝ 一覧 = 「常時選べる3種」＋「購入済み」＋「いまこの作品が使っている1種」
- **みほん・サムネ（`StudioThumb`）・カセットだなの表示も従来どおり**。所持で絞るのは**選択欄だけ**

### 1-4. 確認すること

- 未購入の状態で `jungle` / `canyon` が**選択欄に出ない**
- ショップで買うと**出るようになる**
- `jungle` で保存済みの作品を開くと、**その背景のまま表示され、選択欄にも出る**
- **studio と gamelab の両方**で効く

## §2. みほんの棚に説明文を出す

### 2-1. なぜ必要か（Chat の調査）

`StudioThumb` は **背景＋キャラの初期配置**を描いている。つまりどのみほんも「背景の上にキャラが立っている絵」になり、**並べても見分けがつかない**。名前（`おちものキャッチ` 等）だけが手がかりになっている。

### 2-2. やること

**各みほんに1行の説明文（`desc`）を持たせ、棚で名前の下に出す。**

`src/data/gamelab-samples.js` と、スタジオ側のみほんデータに `desc` を追加し、`WorkshopHome.jsx` のみほん棚で名前の下に表示する。

### 2-3. 文案（gamelab・そのまま使ってよい）

**遊び方が一目で分かることを最優先**にした。「何をすると勝ちか」を必ず入れている。

| id | 名前 | `desc`（案） |
|---|---|---|
| `dropcatch` | おちものキャッチ | じゅうじキーで うごいて、おちてくる リンゴを キャッチ！ |
| `oni` | おにごっこ | おにに つかまらないように、30びょう にげきろう！ |
| `goalrun` | ゴールまで いこう | いわを よけて、ゴールの はたに たどりつこう！ |

段階1・2のみほん（`collect` あつめゲーム／`dodge` よけゲーム／`catch` キャッチ）にも同じ形で1行付けること。**中身を見て Code が書いてよい**が、以下を守る:

- **ひらがな中心・1行（30字以内）**
- **「何をすると勝ちか」を必ず入れる**
- **操作があるものは操作方法を入れる**（じゅうじキー／タップ）
- 語尾は「〜しよう！」「〜キャッチ！」のような呼びかけ

**書いた文案を報告すること。**

### 2-4. スタジオ側

スタジオのみほんは「遊ぶ」ものではなく「見る作品」なので、**何が起きる作品かを1行で**（例: 「ボタンを おすと キャラが おどりだすよ」）。同じ `desc` の仕組みを使う。

### 2-5. レイアウト

- サムネ幅は `THUMB_W: 128` のまま
- 名前の下に1行。**はみ出す場合は折り返す**（切らない）
- **棚が縦に伸びすぎないこと**。伸びるようなら報告して止める（右カラム／画面の縦は既に厳しい）
