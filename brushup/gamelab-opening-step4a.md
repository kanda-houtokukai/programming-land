## §1. 台帳の維持規則を直す（★先にやる・文書のみ）

**規則に穴が見つかった。**
現在 台帳は **32,500字**でしきい値 3.2万を超えているが、**版エントリは10件で規則どおり**。

```
版エントリ10版 : 19,653字（平均 1,965字/版）
固定部         : 12,847字  ← 便③で「ゲームのせってい」未完了タスク等が増えたぶん
```

いまの規則は「版が多すぎる」場合しか想定しておらず、**固定部が育った場合の分岐がない**。
このままだと警告が出続け、**誤警報として無視されるか、原文の圧縮（禁止事項）を招く**。

### 1-1. 台帳と `CLAUDE.md` の両方で、規則を次に差し替える

```
### ★台帳の維持規則（2026-07-24 制定・2026-07-25 改訂・全セッション厳守）

「今どこか」の版エントリは直近10版まで。11版目を足すときは、
最も古い1版を progland-archive-YYYY-MM.md へ原文のまま移してから追記する。

台帳が 3.5万文字（`wc -m` で測る）を超えたら、まず版エントリ数を数える。
・11版以上 → 最も古い版をアーカイブへ原文のまま移す
・10版以下なのに超過 → 固定部（未完了タスク・生きている注意事項・
  ファイルの地図・決定事項）が育っている。完了した項目を消すか、
  アーカイブへ移す
⚠️ 要約・圧縮による削減は禁止（アーカイブは原文保存が目的）
```

### 1-2. 変更点は3つ

1. **3つ目の分岐を追加**（版は規定内なのに超過 ＝ 固定部の見直し）
2. **`wc -m` で測ると明記。** 前便で `wc -c`（バイト）の 59,681 を文字数として報告している。日本語UTF-8では約2倍に出るため、バイトで測るとしきい値が実質16,000字になり誤発火する
3. **しきい値 3.2万 → 3.5万。** 内訳（版19,653＋固定部12,847）から見て、規則を守っていても超える数字になっていた

**§1 を最初の区切りとして単独 push する**（文書のみ・挙動不変）。

## §2. 保護者ガイド `GAMELAB_GUIDE`

### 2-1. やること

1. `src/data/parent-guide.js` に `GAMELAB_GUIDE` を追加
   原稿は `brushup/gamelab-parent-guide.md` に**そのまま貼れる形**で入っている（`export const GAMELAB_GUIDE = { … }` のブロック）。**文面は変更しないこと**
2. `src/gamelab/mode.jsx` の `guide: null,` を `guide: GAMELAB_GUIDE,` に差し替え、import を追加
3. 差し替えに伴い、`guide: null` に付いている「段階3で保護者ガイド全文（段階1は非表示）」というコメントを実態に合わせて更新

### 2-2. 表示側は変更不要のはず（確認だけ）

- `WorkshopHome.jsx` L238 に `{guide && <ParentGuide guide={guide} />}` のガードがある。`null` でなくなれば項目が現れる
- `ParentGuide.jsx` は `guide` を直接受け取り、`title` / `skill` / `body`（配列）/ `tip` を描画する汎用実装。`STUDIO_GUIDE` と同じキー構成なので表示側の改修は要らない見込み
- **実際に開いて表示を確認すること。** 崩れていたら報告

### 2-3. 原稿の要点（レビュー用・変更不要）

- `title`: 「この こうぼうで そだつ ちから」（既存は場所ごとに「この しまで／この スタジオで」と変えている作法に倣った）
- `skill`: 条件と規則の設計・他者視点 ── 「遊ぶ人」のために仕組みを決める力
- `body`: 4段落（スタジオとの違い／操作と規則という新しい考え方／大人が遊んで正直な感想を返す／難しさを認めてみほんへ逃がす）
- `tip`: できた作品を大人が遊んで、正直な感想をひとこと
