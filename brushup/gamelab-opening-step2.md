## §1. マップに建物を置く（`src/components/WorldMap.jsx`）

### 1-1. 看板①を建物に差し替える

`SIGNS` 配列の**1つ目**（`{ left: 69.5, top: 34.13, textTop: 40, flip: false, delay: "1.27s", dur: "3.3s" }`）を**削除**し、同じ座標に `AREAS` のエントリを追加する。

```js
{ key: "gamelab", short: "ゲーム", place: "ゲームこうぼう", img: buildingGamelab, tall: true, left: 69.5, top: 34.13 },
```

- **`AREAS` の末尾に追加**すること。既存エリアの前に挿すと、`SIGNS`/`AREAS` の順序に依存した**ふわふわ揺れの位相が変わる**（スタジオ追加時も末尾に足している）
- `import buildingGamelab from "../assets/studio-assets/gamelab-building.png";` を追加（便①で配置済み・**未参照のためビルド出力に出ていない**状態）
- **`SIGNS` の2つ目（47.3, 29.25）は残す。** 「まだ増える」という予告を維持する

### 1-2. 表示の仕様（Chat が実測済み・確認のみ）

| 項目 | 値 | 根拠 |
|---|---|---|
| `tall` | **true**（82%表示） | 建物はほぼ正方形だがスタジオも同条件で実機承認済み |
| 縦の余白 | **上0・下0** | 既存4棟すべてこの規約。Chat が加工時に合わせ済み。**確認だけでよい** |
| 左右反転 | **不要** | 光源を実測: こうぼう +11.7＝左光源。既存（quiz +5.3 / home +18.6 / typing +41.8 / studio +1.0）と一致。**`flip` は使わない** |

⚠️ スタジオ開店時、**縦に余白のある画像を入れてマップ上で約7%小さく表示される不具合**が起きている（`studio-map-placement.md` に記録）。今回は加工済みだが、実機で既存建物と大きさが揃っているかは見ること。

### 1-3. 座標の微調整

初期値は看板①の座標をそのまま使う。実機で見て調整が要る場合は `studio-map-placement.md` の換算規約に従う:
**dx = r·sin(θ) ／ dy = −r·cos(θ)**（θ＝12時から時計回り・1時=30°・単位は%ポイント）

## §2. 導線の配線

### 2-1. 画面として登録する（`src/App.jsx`）

`Gamelab` を import し、`{save && screen === "gamelab" && <Gamelab … />}` を追加する。
スタジオの登録（`screen === "studio"`）が直前の行にあるので、**同じ形に揃える**こと。

### 2-2. 退出時の処理

スタジオは `exitStudio` で「保存を読み直して `home` へ戻す」ことをしている（XP/コインは `works.js` が保存時に済ませているので、ここは検知と演出だけ＝二重付与なし）。
**こうぼうも同じ処理が必要。** 共用できるなら共用し、**名前が `exitStudio` のままだと誤解を招くので、共用するなら名前を変える**こと（例: `exitWorkshop`）。判断と理由を報告する。

⚠️ ただし**便②の時点で教育接続は未実装**（`grantForNewSave` が `null` を返す）。よって「保存を読み直しても何も増えない」のが正しい状態。**便③で接続したときに、この経路が効くことを確認する**。

### 2-3. `#gamelab-dev` は残す

開発用バックドアは**そのまま残す**こと。マップ経由と両方から入れて構わない。神田さんの検証で使っている。

## §4. 検証

- `npm run verify` 全PASS。**`--update` は実行しない**。
  本件はマップと画面登録のみで `DEFS` に触れないため、**ベースラインは1バイトも動かないはず**。動いたら**手を止めて報告**

- **`gamelab-building.png` がビルド出力に現れること**を確認して報告。便①では未参照のため `docs/assets` に出ていなかった。**出るようになれば配線された証拠**になる
- マップから入って**カセットだなが開き、戻れる**ことを確認

### 実機ゲート（神田さん・iPad）

1. マップに**ゲームこうぼうの建物**が出ている。看板は**1枚に減っている**
2. 建物の**大きさが既存の建物と揃っている**（小さすぎない）
3. **ラベルが「ゲーム」**、タップすると「**ゲームこうぼう** へ いく」と出る

5. **スタジオの「つくる」と紛らわしくない**（← 名前の最終判断）
6. 座標の調整が要るか（既存建物と重なっていないか・草地に乗っているか）
7. **studio・他エリアが変わっていない**
